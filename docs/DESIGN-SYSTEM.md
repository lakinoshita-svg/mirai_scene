# デザインシステム

この文書は画面の色・余白・角丸・状態表現を揃えるための現行ルールです。個別画面で同じ役割の見た目を作る場合も、先に共通部品とデザイントークンを利用してください。

## 正本

- サービス名の表示位置は本文先頭の `serviceIdentity.astro`。中央配置・上下8px、文字は共通 `brandLogo.astro` と `brandLogo.css` を使う。進路ナビ共通ヘッダーにサービス名の表示を依存させない。
- 単独公開用ヘッダーは進路ナビへのリンクとAboutへのリンクを表示する外枠。組み込み版では進路ナビ本体のヘッダーを使用する。

- 色・角丸・影の値は `src/styles/brandStyles.css` の `:root` に集約します。
- 進路ナビへ単独で組み込むバナーは `integrations/shinronavi/templates/banner.css` 内の `--ms-*` トークンを使います。ホスト側のCSSに依存しないため値を内包し、色はこの文書と共通パレットに合わせます。
- 基本部品の見た目は `src/styles/baseStyles.css`、操作状態は `src/styles/interactionStyles.css`、共通配置は `src/styles/layoutStyles.css`、TOP固有の配置は `src/styles/homeStyles.css` で管理します。
- 共通部品のCSSをAstroコンポーネント内へ重複定義しません。コンポーネント固有の構造に限り、そのコンポーネント内へ記述します。
- 新しい色や角丸が必要な場合、既存トークンで表現できない理由を確認してから、用途が分かるトークンを追加します。画面内へ直接カラーコードを書きません。

## 余白の8pxグリッド

- レイアウトの余白・内側余白・要素間隔（`margin` / `padding` / `gap`）は8px刻みに揃え、`src/styles/layoutStyles.css` の `--space-1` 以降のトークンを使います。例：8pxは `var(--space-1)`、24pxは `var(--space-3)` です。
- 進路ナビへ単独で組み込むバナーはホスト側に依存しないよう、`integrations/shinronavi/templates/banner.css` の `--ms-space-*` トークンを使います。
- `0`、`auto`、割合・レイアウト式は役割に応じて使えます。スクリーンリーダー専用の不可視要素に使う `margin: -1px` はアクセシビリティ上の例外です。
- 文字サイズ、線幅、画像の縦横寸法は余白スケールの対象外です。可読性や画像比率を優先し、役割に合う既存値を使います。
- 新しい余白値は8pxグリッドに沿って選び、既存トークンを再利用します。
- 職業名・分野名の長さは固定しません。教材リンクは本文幅の内側で折り返し、狭い画面でも左右の余白を保ちます。

## カラートークン

| 役割 | トークン | 用途 |
| --- | --- | --- |
| 本文 | `--ink` | 見出し、本文などの主要文字 |
| 補助文字 | `--muted` | 説明、補足、メタ情報 |
| ブランド | `--brand-purple` | 主操作、選択、ブランドリンク、進捗 |
| ブランドの明るい色 | `--brand-violet`, `--brand-mid`, `--brand-coral` | ブランドグラデーションなどの装飾 |
| 行動を促す色 | `--action-orange` | 学校検索など、次の行動を促すCTA |
| キーボードフォーカス | `--focus-color` | 全画面で共通のフォーカスリング |
| ページ背景 | `--paper` | ページ全体の背景 |
| 面 | `--surface` | カード、入力欄、ボタン上の面 |
| 区切り | `--line` | 枠線、区切り線、未完了の進捗 |
| ブランドの淡い面 | `--surface-brand-soft`, `--surface-brand-hover`, `--surface-selection`, `--surface-purple` | 説明パネル、ホバー、選択面、補助ラベル |
| 中立の淡い面 | `--surface-neutral-soft` | 比較画像の背景など |
| 強調 | `--yellow` | 小さな装飾的アクセント |

ブランドグラデーションは `--brand-gradient`、淡い装飾面は `--surface-brand-gradient` を使います。文字色の役割は色名ではなく用途のトークンで選び、本文の読みやすさを優先します。

カード画像のテーマ色はコンテンツデータが持つ `--card-bg` と `--card-ink` で表せます。これは職業・テーマの識別に限定し、操作状態や共通UIの配色には流用しません。未設定時の値は中立面とブランド色に揃えます。

## 形・影

| 役割 | トークン |
| --- | --- |
| 小さな部品 | `--radius-small` |
| 入力・操作部品 | `--radius-control` |
| カード | `--radius-card` |
| パネル | `--radius-panel` |
| モバイル用パネル | `--radius-panel-compact` |
| 大きな囲み | `--radius-large` |
| ピル型 | `--radius-pill` |
| 通常カードの影 | `--card-shadow` |
| ホバー時の影 | `--card-shadow-hover` |
| 主CTAの影 | `--cta-shadow`, `--cta-shadow-hover` |

同じ役割のカード、入力、パネルは同じ角丸トークンを使います。独自の影や角丸を作らず、既存の役割に当てはまるか先に確認します。

## 共通の操作状態

- カテゴリや振り返りの選択状態は `.filter.active` と `aria-pressed` を同期します。
- シーンの回答選択は `.choice-control input:checked + label` を見た目の正本とし、キーボードフォーカスも同じラベル上へ表示します。
- ボタン、リンク、入力欄のフォーカスは `--focus-color` のリングに揃えます。
- 同じ操作を別のページへ追加するときは、既存クラスと操作スクリプトを再利用します。ページ限定の例外が必要なら、範囲をページルート配下に限定し、目的をコメントに残します。
- 主操作は `.primary`、補助的なフィルター・選択チップは `.filter` を使います。行動の意味が異なるCTAだけ `--action-orange` を使います。
- CTA内の矢印は本文とは別の要素に入れ、装飾用に `aria-hidden="true"` を付けます。狭い画面で本文が折り返しても、矢印は右側に保ちます。シーン番号も途中では折り返さず、職業名と並ばない幅では行を分けます。

## 追加時の確認

CSS変更では新しいカラーコード、同じ役割の重複宣言、未使用トークン、`aria-pressed` と見た目状態の不一致を確認します。ページ固有CSSが共通部品を上書きする場合は、その画面だけに必要な理由があり、他画面の表示を変えない範囲か確認します。

## シーンと情報ページ

進捗は `sceneProgress.astro` に集約し、全体のグラデーションを3分割のマスクで見せる。未到達部分は中立色。別の選択肢は表示中の2項目の間だけに `--line` の1px罫線を置く。TOP下部の補助導線はPCのリンク列224px・共通内側余白で整列し、SPは1列にする。Aboutの外幅はTOPと同じ `.home` を使う。
