# 教材側の独立した作業コピー

提供元：Downloads/project-2027-main/digital-debris。元フォルダを変更せず、src/publicと設定・lockfileを複製しました。元のdistは複製していません。Gitブランチを作成したものではなく、今後の教材改修をミライシーンと分けて進めるための独立プロジェクトです。

## 今回の変更

- 共通記事の「関連する職業」の後に `MiraiConnections.astro` を追加。対応する体験がある教材だけに表示します。
- `mirai-links.json` はミライシーンの学び対応表と職業JSONから自動生成します。手で編集しません。ミライシーンのルートで `node scripts/syncInquiryLinks.mjs` を実行すると更新できます。
- 元コードの関連記事リンクは `lesson?slug=…` でしたが、同梱の静的ルートは `/forteacher/[slug]/` です。作業コピーでは後者に統一し、一覧・戻り先・ワークシートも同梱ルートに接続します。本番PHP等に移植する場合はルーティングを本番仕様に合わせてください。
- 接続先の既定値は公開予定のGitHub Pages。ローカルで検証する場合は `MIRAI_BASE_URL=http://127.0.0.1:4321/mirai_scene/` を設定します。本番公開前には両サイトの公開状況を確認してください。

## ビルドと起動

このフォルダで `npm ci`、`npm run build`。プレビューは `npm run dev -- --host 127.0.0.1 --port 4322`。

ミライシーン側からこの作業コピーへ戻る検証には、ミライシーン側で `INQUIRY_BASE_URL=http://127.0.0.1:4322/` を設定します。環境変数はビルド時またはdev起動時に指定してください。既定では現在の進路ナビ本番教材へ接続します。

## 引き続き必要な作業

元コードは本番tplに挿入する構成で、本番共通のCSS・ヘッダー・一部画像を含みません。今回追加した導線は単独CSSを持ちますが、教材全体のデザイン刷新は今後の別工程です。今回は本文の大幅改稿や本番への公開は行っていません。
