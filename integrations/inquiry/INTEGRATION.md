# 教材側の独立した作業コピー

提供元：Downloads/project-2027-main/digital-debris。src/publicと設定・lockfileを含む作業プロジェクトです。Gitブランチを作成したものではなく、今後の教材改修をミライシーンと分けて進めるための独立プロジェクトです。

## 接続仕様

- 共通記事の「関連する職業」の後に `MiraiConnections.astro` を表示。対応する体験がある教材だけに表示します。
- `mirai-links.json` はミライシーンの学び対応表と職業JSONから自動生成します。手で編集しません。ミライシーンのルートで `node scripts/syncInquiryLinks.mjs` を実行すると更新できます。
- 静的ルートは `/forteacher/[slug]/`。一覧・戻り先・ワークシートも同じルートへ接続します。本番PHPでは本体のルーティングに合わせます。
- 接続先の既定値は公開予定のGitHub Pages。ローカルで検証する場合は `MIRAI_BASE_URL=http://127.0.0.1:4321/mirai_scene/` を設定します。本番公開前には両サイトの公開状況を確認してください。

## ビルドと起動

このフォルダで `npm ci`、`npm run build`。プレビューは `npm run dev -- --host 127.0.0.1 --port 4322`。

ミライシーン側からこの作業コピーへ戻る検証には、ミライシーン側で `INQUIRY_BASE_URL=http://127.0.0.1:4322/` を設定します。環境変数はビルド時またはdev起動時に指定してください。既定では現在の進路ナビ本番教材へ接続します。

## 引き続き必要な作業

教材は本番tpl向けの構成で、本番共通CSS・ヘッダー・一部画像を含みません。ミライシーンへの導線は単独CSSを持ちます。本番レイアウトとの結合と公開確認は導入担当の作業です。
