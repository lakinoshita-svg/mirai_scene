# 進路ナビ 初期導入用固定版

導入用ファイル：`mirai-scene-initial-2026-10-02.zip`

2026-10-02の19体験を含む既存配布ZIPを、内容を変更せず保存しています。展開後はINSTALL.mdに従って配置してください。導入検証の状況・未対応事項はZIP内のVALIDATION.mdと運用マニュアルに記載しています。

このZIPは追加原稿の作成や通常ビルドで更新されません。初期導入担当へはこのファイルを渡してください。`manifest.json` にファイルのSHA-256と初期原稿のハッシュを記録しています。検証：`npm run release:verify-initial`。

ZIP自体はGit対象外のため、別PCには別途コピーしてください。ソースのmanifestだけでは導入できません。修正版が必要な場合は別の版名で作成し、この版を上書きしません。

制作との分担：[導入とコンテンツ制作の手順](../../docs/DELIVERY-AND-CONTENT.md)
