ミライシーン/学びと体験

学びと仕事を、行き来してみよう。

気になる分野の探究を読んだり、仕事のひと場面を体験したり。自分のペースで理解を深められます。

デザイン →

色・文字・写真を使い、伝わる表現を考える学び。

情報・IT →

使う人の課題を、システムやプログラムで解決する学び。

建築 →

使いやすさや安全性を考え、空間をつくる学び。

保育・幼児教育 →

子どもの育ちや生活を支える学び。

観光 →

人や地域を知り、旅の体験を考える学び。

美容 →

髪や美容の技術と、相手の希望に応える方法を学ぶ。

調理 →

食材や調理技術を知り、食事を届ける学び。

製菓・製パン →

材料や製造工程を知り、お菓子やパンをつくる学び。

動物 →

動物の生態や飼育について理解を深める学び。

農業 →

作物の生育や生産、環境との関係を学ぶ。

経営・商学 →

商品やサービスが届く仕組みや、事業の運営を学ぶ。

イベント →

企画を形にし、多くの人と協力して運営する学び。

出版・メディア →

情報を集め、読み手に届ける方法を考える学び。

映像 →

映像の構成や演出、撮影・編集について学ぶ。

ゲーム →

ゲームのルールや動きを考え、形にする学び。

文学・文化・歴史 →

資料や文化を調べ、知識を人に伝える学び。

“好き”から始まる進路選び。今、将来を決めなくても大丈夫。
