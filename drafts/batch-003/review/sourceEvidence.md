# batch-003 根拠対照表

本文確認日：2026-10-23。対象は10体験・30シーン・90案。同一Codexによる資料照合であり、資料の発行者や実務経験者から個別の回答を得た記録ではありません。

## 結論と判定の意味

10体験の役割と対象物は、下記の職業資料の業務説明に対応します。旅行は店頭での相談・見積もり、データ分析はデータ理解・集計・比較の入口として扱います。職業の全業務や、職場ごとの分担を再現したものではありません。

各選択肢は教材用に作った行動案です。90案の良い点・懸念点は、架空の条件の中で成り立つかを判断しています。資料にその職業の業務が載っていることだけで、その方法の効果・安全性・実務上の最善を実証したとは判定しません。

| 区分 | 確認するもの | この記録での扱い |
|---|---|---|
| 資料で確認する事実 | 職業の業務、色の再現条件、統計の考え方、操作の説明原則 | 資料IDと該当箇所を付ける |
| 計算・原稿内の照合 | 人数と割合、総額、平均、図と本文の情報 | 入力と計算結果・原稿の文を直接照合 |
| 架空の設定 | 店、依頼、家族、試食結果、見積もり、回答データ | 実在する事例や出典掲載事例とは扱わない |
| 教材上の判断 | 三案の比較、期待できること、追加確認 | 編集上の見通し。個々の効果は未実測 |
| 人による確認 | 実務の自然さ、高校生の理解、公開可否 | 実務経験者確認・読解確認・公開承認は未実施 |

## 原稿で区別する必要がある点

| 対象 | 現在の説明の条件 | 根拠・限界 |
|---|---|---|
| デザインの印刷 | 同じ数値・画面でも紙で同じ色になるとは限らない。比べる要素以外の条件をそろえる | colorModels, colorProfiles。用紙だけを原因としない |
| 建築の振り返り | 依頼者の発言と、通路に重なるという観察の範囲を守る | 状況文との照合。完全に通れないという測定結果はない |
| 調理の比較 | 容量と重さを区別し、三案を鍋内の偏り・別取り・途中計量の入口に分ける | portionControl。個々の試作方法は未実証 |
| 編集の80％ | 回答者50人中40人という割合であり、満足の強さの点数ではない | 原稿内の質問と計算。一般に「満足度」という語が常に誤りだと主張するものではない |
| 旅行の費用 | 一泊二日・全額一人分・対象の食事回数・朝食付き宿泊をそろえる | 架空の費目条件。同じ範囲の費用を比較する |
| データの比較 | 取り組み後の回答者集団の平均・割合を見る。個人の変化や施策の因果効果、モデルの予測精度とは分ける | distribution, causalScope。単純な前後差だけでは確定しない |

## 計算の照合

- 編集：40 ÷ 50 × 100 ＝ 80％。分母は回答者50人。地域住民や全参加者の人数ではない。
- 旅行：A案20,000＋8,000＝28,000円、B案26,000円。一人30,000円の見込み残額は2,000円と4,000円。見込み料金が変われば残額も変わる。
- データ：5＋5＋5＋5＋30＝50分、50÷5＝10分。5分が四件、30分が一件で、10分の記録はない。
- 二組の比較図：組ごとに掲載文字と縦横寸法をそろえる。デザイン上の優劣を測定した図ではない。

## 確認を引き継ぐとき

まず原稿JSONを読み、該当する資料の節とこの表を照合します。各案の効果を現場で裏付けたい場合は、元資料の職業紹介だけでは不足します。実務経験者には、その場面で取り得る案か、条件や負担の抜けがないかを全三案について確認してもらいます。高校生には、用語と三案の違いが伝わるかを確認してもらいます。

原稿のハッシュと90案の確認理由は[occupationChecks.json](occupationChecks.json)。この資料の「資料で確認」と、同記録の編集上のpassは異なる意味です。二巡の自己確認を、独立レビューや監修とは呼びません。
