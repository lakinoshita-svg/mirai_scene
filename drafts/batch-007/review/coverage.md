# 収録範囲

集計日：2026-11-10。公開元とbatch-001〜007が対象です。公開・監修の完了件数ではありません。

## 20体験の選び方

既存原稿にない職種を各1体験とし、医療3、営業3、事務2、研究・設計・自動車・航空・福祉・医療事務・金融・法律・服飾・教育・公務・スポーツを各1体験にしています。医療3件は医師、看護師、薬剤師の役割を分けています。営業は食品メーカー、IT、不動産に分け、顧客・商材・協働先を変えています。

## 自社資料18大分類との対応

「ない分野」は、自社資料の18大分類を基準に、少なくとも関連する職種が1件ある状態で確認しています。直接の原文対応があるかは[根拠対照表](sourceEvidence.md)で別に区別します。下位職種すべての網羅を意味しません。

| 自社資料の大分類 | 収録する職種の例（下書き含む） |
|---|---|
| 1. コンピュータ・システム・ゲーム関係 | Webエンジニア、ゲームプランナー |
| 2. 自動車関係 | 自動車整備士 |
| 3. 航空関係 | 航空整備士 |
| 4. 建築・土木・測量・インテリア関係 | 建築士 |
| 5. 放送・音響・映像・イベント関係 | 映像ディレクター、イベントプランナー |
| 6. 美術・デザイン・イラスト・漫画・編集・広告関係 | グラフィックデザイナー、編集者 |
| 7. ビジネス・経理・会計・法律関係 | 経理担当者、弁護士、営業3職種 |
| 8. 理容・美容・ビューティー関係 | 美容師 |
| 9. ファッション・アパレル・家政関係 | ファッションデザイナー |
| 10. 栄養・調理・製菓関係 | 料理人、パティシエ |
| 11. スポーツ関係 | スポーツインストラクター |
| 12. 医・歯・薬学、看護・医療技術関係 | 医師（内科医）、看護師、薬剤師 |
| 13. 医療事務・医療秘書・医療ビジネス関係 | 医療事務 |
| 14. 社会福祉・心理・カウンセリング関係 | 介護福祉士 |
| 15. フラワー・農業・バイオテクノロジー関係 | 農業生産者 |
| 16. 動物医療・動物訓練関係 | 動物園飼育員 |
| 17. 幼児教育・保育・教員関係 | 保育士、小学校教諭 |
| 18. 公務員関係 | 地方公務員（市区町村の行政事務） |

農業生産者は農業技術者と、動物園飼育員は獣医師と同じ仕事ではありません。分類15・16は関連する分野の入口があるという意味です。分類14も心理職全体を介護職で代表するものではありません。

## 次に検討できる未収録職種

歯科医師、理学療法士、作業療法士、診療放射線技師、臨床検査技師、管理栄養士、心理職、社会福祉士、獣医師、農業技術者、電気設備技術者、土木技術者、施工管理、警察官、消防士、輸送・運転職、販売職、総務、食品や生命科学の研究者など。制作候補であり制作済みとは数えません。

300体験は300職種ではありません。大分類・職種・題材・共通テーマを分けて配分します。今回の20体験は各職種の初回体験で、職種内の仕事全体を説明するものではありません。
