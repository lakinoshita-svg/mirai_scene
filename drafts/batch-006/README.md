## 確認の状態

全90シーン・270案について、資料と職種の照合、原稿全体の整合を同一担当が二巡確認しています。別担当者の独立レビュー、実務経験者の確認、高校生の試読、公開承認は未実施です。全件のreviewStatusはeditorial-draftです。

共通カードは既存の4テーマを使います。博物館の複製洗濯板と、三つ折りの文字配置の2シーンには画像があります。[画像一覧](../batch-007/review/imageAssets.md)で用途と確認範囲を確認できます。

## 読み方と確認結果の返し方

1. manuscript.htmlをブラウザで開き、目次から職業・題材を選びます。JSONの操作は不要です。
2. 状況、問い、三案、共通解説、各案の説明・良い点・懸念点、振り返りを読みます。
3. 気になる箇所は「職業・題材・シーン番号・案A/B/C・該当文・理由」を添えて制作担当へ伝えます。資料があればURLや原本の箇所も添えます。
4. 確認者、日付、確認した範囲、残る疑問を記録します。内容の確認と掲載の承認は別に記録します。

原稿の正本はJSONです。閲覧用HTMLへの書き込みはJSONへ自動反映されません。
