## 題材の区別

| 職種 | 今回の題材と既存体験との関係 |
|---|---|
| 動物園飼育員 | 体調変化や採食環境を扱う既存題材に対し、観察記録の書き分け・解説の組み立て・清掃記録をそれぞれ一体験として扱う。 |
| 農業生産者 | 生育のばらつきや定植の準備に加え、規格の照合、収量の見込みと実数、道具を使う作業順を詳しく扱う。出荷の話題は共通するが、比較する対象を区分・予測・工程に分ける。 |
| 物流プランナー | 出荷量、箱、配送遅延、ピッキングの配置に対して、受入単位、返品の所在、棚卸しの照合を扱う。 |
| 博物館学芸員 | 展示説明や他館への貸出に加え、資料の来歴と出所、複製品を使う学習会、画像と台帳の対応を扱う。調査業務の中でも判断材料と成果物が異なる。 |
| 建築士 | 図書室の明るさや音、住宅の玄関収納に対して、店舗の商品搬入と売り場の関係、既存建物の現況と図面の照合を扱う。 |
| データサイエンティスト | アンケートの対象やパンの余りと天候の関係に対し、欠測と計測条件、未使用期間での予測検証を扱う。 |
| 商品企画担当 | 新商品の発想、機能の予算配分、発売後の不便に対して、サイズの品ぞろえと試用条件のそろえ方を扱う。 |
| 図書館司書 | 個人の本探し、郷土資料調査、おはなし会に対し、テーマ展示の構成と目録から現物を探す情報を扱う。展示は既存の本紹介を、資料の選定・配架・受け止め方へ掘り下げる。 |
| イベントプランナー | 企画の優先順位、受付、参加案内に対し、備品の受渡しと返却、集計条件をそろえた実施報告を扱う。振り返りという題材内でも数値と観察の対応を中心にする。 |
| 料理人 | 注文対応、新メニュー、同じ一皿の提供に対し、レシピ記録の再現性と作業台周辺の配置を扱う。再現性は味付けの正解ではなく、計量と工程を共有する題材。 |
| グラフィックデザイナー | ポスターやショップカードに対し、折る紙面の読む順と入稿データの引継ぎを扱う。完成画像の優劣を選ぶ問いではない。 |
| Webデザイナー | ページ内の入口案内に対し、フォーム入力の前後で必要な案内、エラー後の戻り方、試用の観察を扱う。 |
| パティシエ | 持ち帰り、成形、売れ残り、季節の果物に対し、厚さや焼いた位置と焼き上がりの対応を記録する題材。 |
| 編集者 | 取材内容、見出し、数値の出所に対し、同じ道具を指す用語と図・本文の対応を整える。 |
| 旅行プランナー | 行程、天候、混雑、予算内訳に対し、宿泊前後の時間と施設条件、希望と予約内容の照合を中心にする。 |

同じ職種では業務の一部が共通します。題材名だけでなく、仕事の対象、確認材料、作るもの、問いの違いを確認します。同じ正解や文章へ収束させるために職業名だけを入れ替えた原稿は作りません。
