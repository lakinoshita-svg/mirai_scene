## 全シーン・全案の照合

[確認記録の正本](review/occupationChecks.json)には、各原稿のSHA-256、職種との対応、原稿の整合、各選択肢の成立理由を記載する。[職種確認表](review/occupationChecks.md)と[回答確認表](review/answerChecks.md)はこの記録から生成する。

二巡の内容確認では、業務の対象と権限、状況→問い→三案→解説のつながり、選択前の前提、三案の違い、前の回答への非依存、感想の返答の違いを読む。制作担当の自己確認に加え、統合担当も全原稿を読み合わせる。これはAIによる編集確認であり、人の独立レビュー・専門家監修ではない。

## 共通判定

| 観点 | 判定と確認の範囲 |
|---|---|
| 対象・目的 | 高校生が興味から試せる場面。ガイダンス参加や適性判定を前提にしない |
| 業務の範囲 | 資料の職務と対象物を照合し、専門職との分担と相談相手を明示 |
| 状況の十分さ | 道具、資料、調整可能な範囲などを選択前に示す |
| 案の比較 | 何から詳しく確認・試作するかを選び、必要な確認を省く選択にはしない |
| 解説の因果 | 行動で得られる情報と、なお確認が必要な範囲を各案で書き分ける |
| 仕事らしさ | 画像配信、所持数、取材原稿、毛先、乗り場、材料量など具体物を扱う |
| 読みやすさ | 専門語を説明し、一般的な激励だけで終わらせない。高校生の試読は未実施 |
| 画像 | 画像を見分ける設問ではないため追加画像なし |
| 学びへの接続 | 既存の学びIDを参照し、体験した行動と学びの関係を示す |
| 証跡・実装 | 構造・ハッシュ・隔離ビルド・画面確認の結果は以下に記録する |
