# ミライシーン：10体験の確認用原稿

このフォルダには、追加制作した10体験・30シーン・90選択肢を収録しています。

## 内容を読む

1. [原稿一覧](manuscript.html)をブラウザで開きます。
2. 職業を選び、状況、問い、三つの選択肢、共通解説を読みます。
3. 各選択肢の説明・良い点・懸念点と、最後の感想への返答を確認します。

| 職業 | 今回の題材 |
|---|---|
| Webエンジニア | 写真の読み込みと配信の検証 |
| ゲームプランナー | 操作結果が伝わる表示と反応 |
| 編集者 | インタビュー記事の構成と原稿整理 |
| 保育士 | 絵本を楽しむ子どもの異なる反応 |
| 美容師 | 髪を伸ばす希望とカット前後の相談 |
| 旅行プランナー | 公共交通の乗り継ぎと滞在時間 |
| 料理人 | 使える材料の量と一皿の材料費 |
| パティシエ | 焼き菓子の製造と箱詰めの計画 |
| イベントプランナー | ステージの切り替えと進行表 |
| 建築士 | 設計図書と工事の照合 |

## 確認してほしいこと

- この職業が実際に関わる対象・判断になっているか。
- 状況を読むと、三つの行動を比較できるか。
- 説明・良い点・懸念点が、選んだ行動につながっているか。
- 高校生に伝わらない言葉、断定しすぎる表現がないか。

連絡する際は「職業／シーン番号／選択肢A・B・C／気になる文／理由」を添えてください。JSONを直接編集しなくても確認できます。

編集元は直下の10個のJSONです。原稿一覧はJSONから生成します。全件は内容確認待ちの下書きで、実務経験者の確認・公開承認は別途必要です。このフォルダは本番の公開対象外です。

確認用ZIPを受け取った場合は、展開してこのフォルダの`manuscript.html`を開いてください。ZIPは原稿と確認資料の受け渡し用です。進路ナビへの掲載には、掲載原稿の決定後に制作元でビルドし、導入先に合う配布物を作ります。
